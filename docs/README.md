The QA and review reports mention screenshot files captured during test runs. Those images are generated by the test
suites and are not committed. Run `npm run test:e2e` to recreate them locally.

`media/` holds the banner, logo, social preview and promo video; `screenshots/` holds the README screenshots
(regenerate with `node scripts/readme-screenshots.mjs` after `npm run build`).
